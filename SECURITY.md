# Security policy

## Reporting a vulnerability

Please do not open a public issue for a potential security vulnerability.
Create a private [GitHub security advisory](https://github.com/Frens98/hikconnect-nvr/security/advisories/new)
instead.

Never include an AppKey, SecretKey, access token, camera/NVR serial number, or
temporary stream URL in a report. Provide redacted logs and clear reproduction
steps instead.
